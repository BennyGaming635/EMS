# EMS Operations Hub

A fully responsive and adaptive Next.js emergency operations app inspired by BART-style warning systems, expanded to support:

- Emergency incident management
- Vehicle/fleet operations management
- 911 call workflow management

## What this app includes

- Unified operations queue across all three domains
- Live activity behavior with auto-refresh simulation and event feed
- Real-time style summary cards and status indicators
- Search and filter controls by domain and priority
- Mobile-first responsive layout that adapts to tablet and desktop

## Tech stack

- Next.js (App Router)
- React
- TypeScript
- CSS (global styles)

## Run locally

```bash
cd /home/runner/work/EMS/EMS
```

Then open `http://localhost:3000`.
